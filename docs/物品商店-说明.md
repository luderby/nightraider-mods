# Night Raider 物品商店 Mod（v1.3.5）

一个夜袭者（Night Raider，Steam appid 2719290）插件，在游戏内提供一个可以搜索和购买任意物品的商店界面，
并可按物品稀有度给商店行和游戏自带背包格子上底色。

---

## 1. 功能

### 商店

- **游戏内商店窗口**：按 `F8` 打开 / 关闭（可在配置里改键）。
- **搜索框**：直接输入物品名字查找，支持：
  - **中文名**（例如「头盔」「9mm」「药」）
  - **英文名**（例如 `heal`、`AK`）
  - **物品 ID**（例如 `4000`）
  - 只输入一部分即可；搜索时**不区分页签**，会自动从全部物品里找
  - 结果按「完全相同 → 名字开头 → 包含」排序，同档内便宜的排前面
  - 点「清空」按钮清除搜索；点击其他位置结束输入
- **七个页签**：武器 / 武器配件 / 装备 / 药剂 / 食物 / 材料 / 全部
- **上架全部物品**：共 **1373 件**，包括只能卖钱的财宝、银行卡、未启用遗留物，一件不漏
- **价格倍率可手调**：点倍率框手输（回车确认），`-`/`+` 按 0.25 步进，`重置` 回 1.0
  - 最终价格 = **物品售价 × 倍率**
  - “物品售价”就是游戏里回收商人给你的那个数字（等于 `物品价格 × 0.5`），所以倍率 2 就是回收价的 2 倍，倍率 1 等于“按回收价买”
- **购买数量可调**：每行 `-`/`+` 调整，自动受堆叠上限限制
- **自动入库**：优先放背包；背包放不下时自动放进已解锁的仓库（A~F），并立即写盘保存
- **翻页 / 滚动**：`上一页`/`下一页` 整页翻，鼠标滚轮按行滚动
- **详情面板**：显示物品名、ID、分类、**稀有度**、售价、单价、总价、堆叠上限和游戏内描述
- **输入保护**：商店打开时屏蔽游戏自身键鼠输入，在搜索框/倍率框打字不会让角色乱跑或开枪（可关闭）
- **截图键**：`F9` 把当前画面存到 `BepInEx/Screenshots`

### 稀有度底色（v1.3.0 新增，v1.3.1 改按掉落机制定档，v1.3.2 支持热改配置）

- **商店列表行**按稀有度上底色，选中行会把档位色和选中蓝混合，所以“选中哪行”和“多稀有”能同时看清。
- **游戏自带背包 / 箱子格子**也按稀有度上底色，覆盖游戏原来的分类色（蓝=消耗品、紫=配件）。
- **不动这些格子**：正在拖拽时完全不着色（否则会破坏放置高亮）；**已锁定（红）** 和
  **已标记（金）** 的格子保留游戏原色，因为那是你自己设的状态。
- 五档：**普通 / 优良 / 稀有 / 史诗 / 传说**，名称和颜色都在配置里可改，不用重新编译。
- 档位来自一张**你可以直接编辑的 CSV**：`BepInEx\config\NightRaider_item_tiers.csv`，
  改完按 `F8` 就生效（自动热重载），不用重启游戏。

> **重要前提**：游戏**没有**稀有度字段（已核对反编译代码，`ItemData` / `CurrentItemData`
> 都没有 rarity/quality/grade 成员，`EquipmentData.itemLevel` 是死字段）。
> 所以稀有度不是"读"出来的，而是由这张 CSV 定义的。
>
> v1.3.1 起，表按**掉落机制**定档（参考难度 `E = 5`，即开局默认配置 + 最低难度）：
>
> - **物品**：按掉落权重（`P(抽中池) × 条目数 / 池大小`）在同类内分位切档，价格只做离群修正；
> - **武器**：按最早解锁的 `Goods_Weapon_Map1..6` 层级 + Map 可用性几率双重决定；
> - **装备**：按工作台升级链（简易/强化/军用/特种）拉伸到 1/2/4/5 档；
> - **背包**：按工作台升级链 1:1 映射 1–5 档；
> - **任务/剧情物品**（4717-4732）统一 4 档，方便在背包里辨认。
>
> 详见 **[ITEM_TIERS.md](ITEM_TIERS.md)**。

## 2. 安装

已经把文件装到游戏里了，正常情况下**不需要再做任何操作**，直接启动游戏即可。

若要重新安装（例如 Steam 校验文件后 BepInEx 被删掉），把 `NightRaider_ItemShop_v1.3.5` 里的内容全部复制到：

```
G:\steamruanjian\steamapps\common\Night Raider\NightRaider\
```

复制后该目录应当长这样：

```
NightRaider\
├── NightRaider.exe
├── winhttp.dll                  ← BepInEx 加载器
├── doorstop_config.ini          ← BepInEx 加载器配置
├── .doorstop_version
└── BepInEx\
    ├── core\                    ← BepInEx 本体（不要动）
    ├── plugins\
    │   ├── NightRaider.RareShop.dll        ← 本 Mod
    │   └── NightRaider_item_tiers.csv      ← 稀有度表模板（配置被删时用来自动恢复）
    ├── config\
    │   ├── nightraider.rareshopplugin.cfg  ← 本 Mod 配置（首次运行自动生成）
    │   └── NightRaider_item_tiers.csv      ← 稀有度表（改这个）
    └── LogOutput.log            ← 运行日志，出问题先看这里
```

> 两个 CSV 内容相同。`config` 里那份是**你编辑的对象**，`plugins` 里那份是**模板**：
> 如果 `config` 里那份被删掉，插件下次启动会自动从模板复制回来。

## 3. 使用

1. 从 Steam 正常启动游戏，**读取你的存档**（在营地里）。
2. 按 `F8` 打开商店。
3. 找东西有两种方式：
   - **搜索**：点上方搜索框，输入名字（中文/英文/ID），列表实时过滤
   - **翻页签**：点 `武器` / `装备` / `材料` 等分类，或用 `全部`
4. 点左侧物品行选中 → 需要多个就点 `+` → 点 `购买`。
5. 点击倍率框，键入数字（例如 `2.5`），回车确认。
6. 再按 `F8` 关闭。

> 商店在尚未读取存档时（主菜单）也能打开，但那时没有商品可买；请先进入存档。

## 4. 配置

文件：`NightRaider\BepInEx\config\nightraider.rareshopplugin.cfg`

### General / Shop

| 配置项 | 默认 | 说明 |
|---|---|---|
| `General/ToggleKey` | `F8` | 开关商店的按键。游戏默认键位里 F8 未被占用（F1/F2/F5/F9 已被游戏用掉）。 |
| `General/ScreenshotKey` | `F9` | 截图键。 |
| `General/SuppressGameInputWhileOpen` | `true` | 商店打开时屏蔽游戏键鼠输入。 |
| `General/DebugLog` | `false` | 打开后会在日志里输出各分类的商品数量，便于排查。 |
| `Shop/DefaultPriceMultiplier` | `1` | 每次打开商店时的默认倍率。 |

### Rarity

| 配置项 | 默认 | 说明 |
|---|---|---|
| `Rarity/ColorShopRows` | `true` | 商店列表行按稀有度上底色。 |
| `Rarity/ColorBagCells` | `true` | 游戏自带背包/箱子格子按稀有度上底色。 |
| `Rarity/ReloadTableOnOpen` | `true` | 每次开商店重读 CSV，改完表不用重启游戏。 |
| `Rarity/ShopRowBrightness` | `0.30` | 商店行着色强度，0=不着色，1=全亮。 |
| `Rarity/BagCellBrightness` | `0.60` | 背包格子着色强度。 |
| `Rarity/Tier1Name` … `Tier5Name` | 普通/优良/稀有/史诗/传说 | 各档显示名称。 |
| `Rarity/Tier1Color` … `Tier5Color` | `C9C9C9`/`5FBF5F`/`4D8CE6`/`A85CD9`/`F2A33C` | 各档底色，十六进制 `RRGGBB`。 |

## 7. 兼容性与注意事项

- 游戏用 Unity 2022.3.49 + **Mono** 后端，本 Mod 是 BepInEx 5 插件。
- 已验证游戏版本：Steam 版 `Version 1.70`（`Assembly-CSharp.dll` 写入时间 2026/10/14 0:15:58）。
- **游戏更新后可能失效**：Mod 依赖 `DataHub.itemDataDic`、`ManagerBase<T>`、`CurrentDataHub.myBag`
  等内部结构，背包着色还依赖两个**私有字段名**。若更新后报错或背包不再着色，
  先跑 `src/MetaCheck` 检查字段名，再看 `BepInEx\LogOutput.log`。
- 打开商店**不会暂停游戏**（和背包/手册一样）；在战斗中开商店要自己注意安全。
- 购买会**立即写盘**（`SaveBag` / `SaveDepot` / `SaveRecord`），不会因为意外退出丢东西。
- 该游戏的 Steam 云同步（AutoCloud）在客户端日志里显示为 disabled，不存在“云存档覆盖本地”的冲突。
- 搜索框是自绘的（游戏自带输入框在这个版本里是死代码），直接键入即可，不支持复制粘贴。
  中文输入依赖系统的输入法把字符交给 Unity，正常打字就可以。

## 8. 已知限制

- 武器/装备行只显示价格与数量，没有在商店里预览详细属性；把鼠标悬停在游戏背包里可以看。
- 商店内不能卖东西，只能买。
- **稀有度是外部表定义的，不是游戏数据**：游戏里不存在客观稀有度，
  表里没有的物品不会被涂色（保留游戏原色），想让某件东西换档就直接改 CSV。
- **背包着色不含装备栏槽位**（头盔/护甲/武器格）：那里的子物体层级是嵌套的，
  且游戏用红色表示"不可装配"，改色容易和这个语义打架。目前只覆盖主背包和容器/箱子格子。
- 若游戏把 `F8` 也占用了（目前没有），或你想换键，改配置里的 `ToggleKey` 即可。
