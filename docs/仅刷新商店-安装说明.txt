========================================================================
  Night Raider  刷新商店（F7）——  ① 先看我
========================================================================

  这个包只有 1 个功能：刷 新 商 店（游戏内按 F7）。
  不含「物品稀有度底色」，不会给物品格子加颜色，也不含 F8 商店。


------------------------------------------------------------------------
  怎么装（两种情况，程序会自动识别）
------------------------------------------------------------------------

  解压整个压缩包到任意位置（比如桌面），然后双击：

        一键安装.bat

  程序会自己搞定一切，包括找到你的游戏目录。

  ┌─ 如果你【从没装过 MOD】─────────────────────────────┐
  │  程序会把 BepInEx 运行库一起装好，装完直接就能用。   │
  │  你不需要事先装任何东西。                            │
  └──────────────────────────────────────────────────────┘

  ┌─ 如果你【已经装过别的 MOD / 整合包】─────────────────┐
  │  程序会检测到，然后【只补上刷新商店这一个】。        │
  │  你原有的运行库、其它 MOD，一个字节都不会被改。      │
  └──────────────────────────────────────────────────────┘

  装完进游戏，按 F7 就是刷新商店。


------------------------------------------------------------------------
  它为什么不会和别的 MOD 冲突
------------------------------------------------------------------------

  这是本安装程序的设计原则：**缺什么补什么，绝不覆盖已有的东西。**

  已经存在的文件              程序的处理
  --------------------------  ------------------------------------
  winhttp.dll                 已有 → 原样跳过，不覆盖
  BepInEx\core\ 运行库        已有 → 原样跳过，18 个文件都不动
  BepInEx\plugins\ 里别的 MOD 只往目录里【新增】本 MOD 的文件
  稀有度表 NightRaider_item_  已有 → 跳过（你用着的表不会被冲掉）
    tiers.csv
  刷新商店自己（重复安装）    先备份旧的，再更新
  同名文件被本程序覆盖的      一律先备份，可完整还原

  具体来说：

  · 每个 MOD 都有自己的 dll 文件名，互不干涉。本包只写这两个：
        BepInEx\plugins\NightRaider.RareRefresh.dll
        BepInEx\plugins\NightRaider_item_tiers.csv

  · 共用的 BepInEx 运行库**只在游戏完全没有时才安装**。
    游戏里已经有了，就一个字节都不碰 —— 这是最容易冲突的地方，已避开。

  · 你之前改过的配置（按键、刷新费用）和稀有度表都不会被覆盖。

  所以你以后想再装别的 MOD，直接把文件放进 BepInEx\plugins\ 就行，
  不会有冲突。


------------------------------------------------------------------------
  目录里都是什么
------------------------------------------------------------------------

  一键安装.bat            ← 双击这个安装
  一键卸载.bat            ← 双击这个卸载
  install.ps1 / uninstall.ps1   上面两个 bat 实际调用的脚本
  ① 先看我 - 安装说明.txt        本文件

  winhttp.dll                    ┐
  doorstop_config.ini            │ BepInEx 加载器（游戏已装过就不使用）
  .doorstop_version              ┘
  BepInEx\core\                  BepInEx 运行库，18 个文件
  BepInEx\plugins\               NightRaider.RareRefresh.dll  ← 刷新商店本体
                                 NightRaider_item_tiers.csv   ← 稀有度表
  BepInEx\config\                NightRaider_item_tiers.csv   ← 稀有度表副本


------------------------------------------------------------------------
  安装后：怎么用 / 怎么改 / 怎么确认
------------------------------------------------------------------------

  【怎么用】
      进游戏，按 F7 打开刷新商店。整页刷新一次 50000 GP。

  【怎么改按键或价格】
      第一次进游戏后，会自动生成这个配置文件：
          BepInEx\config\nightraider.rarerefresh.cfg
      用记事本打开，改这两行，存盘后重进游戏：
          ToggleKey         = F7        ← 想换键就改成 F9 之类
          PageRefreshCostGP = 50000     ← 刷新费用

  【怎么确认装上了】
      用记事本打开：
          BepInEx\LogOutput.log
      搜索 Refresh Shop，应该能看到：
          Night Raider Refresh Shop v1.1.0 已加载。开关按键: F7


------------------------------------------------------------------------
  常见问题
------------------------------------------------------------------------

  Q: 按 F7 没反应？
  A: 1) 装完必须**完全退出游戏再重新进**，BepInEx 只在启动时读一次。
     2) 确认 BepInEx\plugins\ 里确实有 NightRaider.RareRefresh.dll。
     3) 按键被占用 → 把配置里的 ToggleKey 改成别的键。

  Q: 会不会覆盖我整合包里的东西？
  A: 不会。运行库已有就跳过；别的 MOD 的 dll 完全不碰。
     只有刷新商店自己这一个文件会在重复安装时被更新（且会先备份）。

  Q: 我不想要物品上色，这个包会上色吗？
  A: 不会。这个包里没有任何上色代码，上色是另一个 MOD
     （NightRaider.RareTint.dll）负责的，本包不含它。

  Q: 我之后还想装「物品底色」，会冲突吗？
  A: 不会。底色 MOD 有自己的 dll 文件名和配置，装上去就是多一个功能，
     两个 MOD 共用同一张稀有度表，互不影响。

  Q: 想卸载怎么办？
  A: 双击「一键卸载.bat」。
     它只会拿掉刷新商店，你之后装的其它 MOD 会原样保留。
     （它不会整目录删除 BepInEx，所以不会误伤别的 MOD。）

  Q: F7 和 F8 能同时开吗？
  A: 不要。两个面板打开时都会屏蔽游戏输入，会互相拦截点击。
     关掉一个再开另一个。
